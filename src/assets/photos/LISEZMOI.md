# Photos du site

Déposez ici les photos, nommées d'après l'emplacement qu'elles remplissent
(extensions acceptées : .webp, .avif, .jpg, .jpeg, .png), puis relancez
`npm run build`.

Exemple : `accueil-hero.jpg` remplace l'emplacement « accueil-hero ».

La liste complète des emplacements encore vides s'affiche à la fin de chaque
génération. Conseils : 2400 px de large pour les photos plein cadre
(`*-hero`, `actu-une`), 1200 px pour les autres, format WebP ou JPEG
qualité ~80.
